# Security Policy

## Supported versions

Security fixes are provided for the latest released minor version.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private
security advisory reporting for this repository, or email `info@kupahrej.cz`.
Include the affected version, reproduction steps, impact, and any suggested
mitigation. Never include live OAuth credentials, purchased codes, or customer
data in the report.

We aim to acknowledge a report within five business days. Publication should be
coordinated until a fix is available to users.
